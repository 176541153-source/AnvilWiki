## 你现在在哪,这章解决什么

站上线了,Google 在收录了。但访客来了你没东西卖——这一章把**广告位**开起来,访客看到广告,Google 就给你分钱。

同时要建立**保鲜节奏**:游戏攻略最怕过期。兑换码过期了没人管、Boss 改版了攻略还教旧打法——玩家来一次发现是废纸,就不来第二次,Google 也会把排名让给别人。

## 这章做完你会得到

- 广告位上线,开始积累收入
- 一套每周一 30 分钟的固定动作,网站永不过期

## 先认识几个词

- **AdSense**:Google 的广告中介。它把广告放进你的页面,广告被看到/被点击,Google 按月把钱打给你。
- **RPM**:每一千次浏览挣多少钱。排行榜页和兑换码页通常 RPM 最高。
- **Lighthouse 4×100**:Google 给网站做的体检,速度/无障碍/规范/SEO 四项各 100 分。这套模板开箱就是满分——广告位是懒加载的,开了也不掉分。

## 第一步:申请 AdSense(先自查,别急着交)

**申请前对照清单**(缺一项都容易被拒):

- ☐ 自有域名(第 4 章买的;pages.dev 免费域名基本过不了审)
- ☐ 15 到 20 篇真实内容(不是空壳)
- ☐ 隐私政策页和服务条款页(**模板已经自动内置**了 `/privacy-policy` 和 `/terms-of-service`,不用你做)
- ☐ 网站打开无死链(`pnpm check-links` 通过)

**怎么做**:打开 [adsense.google.com](https://adsense.google.com) → 添加你的网站 → 等审核(几天到两周)。
**被拒了怎么办**:看它给的原因,九成是「内容价值不足」——回去用第 3 章的套路再写 5 到 10 篇,过两周再申请,不影响后续。

## 第二步:把广告编号填进网站

**做什么**:审核通过后,AdSense 会给你 1 个发布商编号和若干广告位编号。网站预留了 4 个开关,填上就亮。
**怎么做**:

1. AdSense 后台 → **广告** → 按广告位,拿到你的发布商 ID(样子像 `ca-pub-一串数字`)和各广告位编号。
2. Cloudflare → 你的项目 → **Settings** → **Variables and Secrets**,添加 4 个变量:

| 变量名(照抄,区分大小写) | 填什么 |
|---|---|
| `PUBLIC_ADSENSE_CLIENT` | 你的发布商 ID(ca-pub- 开头) |
| `PUBLIC_ADSENSE_SLOT_STICKY` | 底部横幅广告位编号 |
| `PUBLIC_ADSENSE_SLOT_SIDEBAR` | 侧边栏广告位编号 |
| `PUBLIC_ADSENSE_SLOT_INCONTENT` | 文章中间广告位编号 |

3. 保存并重新部署。

**你会看到**:网站底部/侧栏/文章中间出现广告(新广告位可能要几小时到几天才有内容填充,先空白是正常的)。
**确认做对了**:四个变量都在 Cloudflare 里(一个不填,对应位置就不显示——这是设计好的,想只开一处就只填一处)。收入全归你,没有平台抽成。

> 评论功能和访问统计也是同样的开关玩法(评论叫 Giscus,靠 GitHub 仓库讨论区;统计可选 Google Analytics 或 Cloudflare 自带的)。需要时看开发手册「集成」章,有完整步骤。

## 第三步:建立每周一 30 分钟节奏

固定时间做固定的事,是你网站不过期的唯一秘诀。

### 动作一:跑保鲜检查,把报告变成待办(15 分钟)

**做什么**:让网站自己告诉你哪些页过期了。
**怎么做**:终端输入:

```bash
pnpm refresh-audit
```

**你会看到**:一张清单。两种级别——**P0 最紧急:兑换码页超过 7 天没更新(拖过 30 天问题升级);P1 次紧急:Boss 攻略和排行榜这两类页面超过 90 天没更新**(只有这两类会产生 P1,因为它们过时会误导玩家;其他页面不会)。然后把清单粘贴给 AI 助手,让它整理成待办:

```text
下面是我的 pnpm refresh-audit 报告:
<粘贴报告>
把 P0/P1 转成可执行清单:
1. 需要我提供新数据的页面 → 逐页列出具体要什么(最新码列表/新版本机制改动)
2. 我确认内容仍准确、只需刷新的页面 → 把 lastModified 更新为今天
3. gameVersion 落后的页面单独列出
不许自行修改任何内容事实。以复选框清单输出。
```

> 注意:仓库里那个「每周自动检查并开 issue」的功能,**默认只在 AnvilWiki 官方仓库生效,你的站收不到自动提醒**——所以要自己每周跑这一条。想让 GitHub 自动开 issue 提醒也可以:删掉 `.github/workflows/content-pipeline.yml` 里 `if: github.repository ==` 那一行条件(让 AI 助手帮你删,一句话的事)。

### 动作二:更新兑换码(10 分钟)

去官方推特/Discord 收集新码和确认过期的旧码,然后:

支持技能的 AI 助手直接说(斜杠命令):

```text
/anvil-update-codes 新码:<code列表>;已确认过期:<code列表>
```

普通提示词版:

```text
更新 src/content/wiki/en/codes/ 下的 codes 文章:新码追加到 frontmatter active 最前;
过期码 status 改 expired(保留不删除);lastModified 改今天;title/summary 中码数量与年月同步;
若存在其他语言版,同步数据(code 字段不译,reward 等文案译)。
写完运行 pnpm check-content && pnpm build,全绿才算完成。
```

**确认做对了**:兑换码页出现新码,过期码搬进「已过期」表格(不删——还有人搜「旧码还能用吗」,留着接长尾流量)。

### 动作三:收尾(5 分钟)

`git push`(Cloudflare 自动重新上架)→ 打开 GSC「效果」页看这两天哪些词带来点击 → 挑 1 到 2 个上涨的词,下周用第 3 章套路写对应新页。

## 每月一次(各 10 分钟)

```bash
# 1. 有多语言站才跑:看翻译缺了多少
pnpm check-i18n --strict

# 2. 把模板作者的更新搬进来(第一次用,三行都要跑)
git remote add upstream https://github.com/PNGTRID/AnvilWiki.git
git fetch upstream
git merge upstream/main
```

第二组命令的意思:把官方仓库(叫 upstream)设为关注对象,拉取它的最新版,合并进你的站。**如果终端出现 CONFLICT 字样别慌**:把冲突文件名告诉 AI 助手,说「配置和内容保留我的,代码听官方的」,让它逐个解决——这一步本来就适合让 AI 做。详细讲法在开发手册「同步」章。

再花 10 分钟看 AdSense 报表:哪类页面 RPM 最高(通常是排行榜和兑换码)→ 下月多写哪类。

## 季度动作:SEO 体检(把这段发给 AI 助手)

```text
对本站做 SEO 体检,只读不改:
1. SITE_URL(wrangler.toml [vars] 或 .env)含 https:// 且为正式域名
2. 全部文章 title≤80、description 40–165、summary 为直答(列违规清单)
3. og:image/twitter:image 为绝对路径
4. noindex 是否误用
5. 运行 pnpm check-sitemap;build 后运行 pnpm check-links,报告非 200/死链
6. 多语言 hreflang 覆盖是否完整
输出问题表:文件/问题/建议修法,经我确认后再改。
```

## 对收入的合理预期

- 黄金窗口是游戏爆发后的 **2 到 8 周**。窗口内 Google 逐步给你排名,**头 1 到 2 周收入为零是正常的**,不是失败了。
- 收入公式 ≈ 页面数 × 排名 × 每千次浏览收入。前 30 天拼页面数量,之后拼排名(保鲜 + 内链)。
- 第一个站跑通后,第二个站边际成本极低——选品、建站、产页、部署、运营,这本手册你已经完整走了一遍。

## 卡住了怎么办

- **「广告位一直空白」**:新站新广告位,填充要等几小时到几天;再确认 4 个变量名拼写完全一致(区分大小写)。
- **「AdSense 被拒」**:基本是内容量不够,补 5 到 10 篇真实攻略再申请。
- **「忘了每周跑检查」**:在手机日历建一个每周一重复的提醒,标题写「30 分钟保鲜」。

## ✅ 验收(全部成立才算完成)

- 广告在线上真实展示(若已通过 AdSense)
- 本周跑过一次 `pnpm refresh-audit`,P0 清零(兑换码页 7 天内更新过)
- ☐ 连续三周,同一时间做了这三件事
- ☐ 看得懂 GSC「效果」页:哪几个词带来了点击

## 学完之后

三岔路口:**继续周节奏运营**;**进[开发手册](/zh/landing/docs/architecture)深度定制你的站**(加栏目、加语言、换皮肤、开评论统计);或者**把你的站提 PR 加进 AnvilWiki 官网展示墙**(改 `src/config/landing.ts` 里的 showcase 数据)——你的真实案例,就是这套模板最好的广告。
