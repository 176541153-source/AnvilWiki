Codes are the fastest free boost in Anvil Quest. This page is re-tested daily (last pass: August 23, 2026); expired codes move to the bottom table so you can see what you missed.

## How do I redeem codes in Anvil Quest?

Press the gear icon (settings) in the top-right corner, click **Redeem Code**, paste the code, and confirm. Codes are case-sensitive — copy them exactly from the list above.

## What do the rewards actually give you?

| Code | Reward | Worth it? |
| --- | --- | --- |
| FORGE-2026 | +500 Gold | Yes — half a weapon upgrade early game |
| EMBERBORN | 2× XP for 30 min | Yes — pop it right before a boss run |
| ASHENKEEP | Cosmetic set | Cosmetic only, no stat effect |
| NEWPLAYER | Starter bundle | Only works once per account |
| ANVIL-DAWN | Dawn Anvil charm | Yes — +10% gold drops for an hour, pop it before a farm session |

## Why do codes stop working?

Codes expire on a schedule set by the developer (usually monthly or tied to update milestones), and some are one-per-account. If a code above fails, it likely expired since our last test — check back tomorrow; this page is updated daily.

Coins from codes go furthest early: the [beginner guide](/guides/beginner-guide/) lists what to buy first, the [weapon tier list](/guides/weapon-tier-list/) shows what is worth crafting, and the [Emberfang guide](/bosses/emberfang/) is the first boss those upgrades unlock.
